## 🤝 How to Contribute

We welcome community additions! Follow these simple steps:

1. **Fork** this repository.
2. Add your tool entry to the matching category table above in alphabetical order.
3. Ensure the tool has a **usable free tier**, **free forever plan**, or is **open source** (no affiliate/referral links).
4. Submit a **Pull Request** titled `Add [Tool Name]`.
